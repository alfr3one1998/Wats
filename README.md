# دليل عملاء واتساب

لوحة عربية تحفظ العملاء الذين يرسلون إلى رقم **WhatsApp Business Platform** تلقائيًا. عند وصول رسالة جديدة، تحفظ اللوحة:

- رقم واتساب للعميل.
- الاسم الظاهر في ملفه على واتساب إن وصل من Meta.
- أول وآخر وقت تواصل، وآخر رسالة، وعدد الرسائل.
- اسم مخصص ووسوم تضيفها أنت من لوحة الإدارة.
- ملف CSV جاهز للتصدير والاحتفاظ بنسخة من الدليل.

> لا تستخدم هذه النسخة واتساب ويب أو أي طريقة التفاف على واتساب. الربط مبني على Webhook الرسمي من Meta، لذلك لا يعرّض رقم المحل للحظر بسبب أتمتة غير رسمية.

## تنبيه مهم

لا يوجد API رسمي يجعل موقعًا ما يضيف جهة الاتصال داخل تطبيق واتساب أو داخل جهات اتصال هاتفك تلقائيًا. هذه اللوحة تحفظ العملاء داخل قاعدة بياناتك، ثم تستطيع تصديرهم كـ CSV واستيرادهم إلى Google Contacts أو الهاتف عند الحاجة. لاحقًا يمكن إضافة مزامنة Google Contacts بموافقتك.

## التشغيل على الكمبيوتر

يتطلب Node.js 22.5 أو أحدث. لا توجد مكتبات خارجية للتثبيت.

```bash
cp .env.example .env
npm start
```

افتح `http://localhost:3000`.

في التشغيل المحلي فقط، إن لم تنشئ ملف `.env` تكون كلمة المرور المؤقتة `admin123`. لا تستخدمها إطلاقًا في النشر.

## اختبار سريع قبل ربط واتساب

1. سجّل الدخول.
2. اضغط **أضف رسالة تجريبية**.
3. أضف رقمًا بصيغة دولية، مثل `9665XXXXXXXX`.
4. سترى العميل في الدليل ويمكنك إضافة اسمه ووسومه.

## ربط Meta WhatsApp Business Platform

قبل الخطوات، تحتاج رقمًا مضافًا إلى WhatsApp Business Platform وحساب Meta Business مناسبًا. إذا كان رقم المحل مستخدمًا حاليًا في تطبيق واتساب، راجع خيارات Meta الخاصة بربط الرقم/التعايش قبل تغييره.

1. انشر المشروع أولًا على رابط HTTPS عام (مثل `https://wats.example.com`).
2. في [Meta for Developers](https://developers.facebook.com/)، أنشئ تطبيقًا وأضف منتج **WhatsApp**.
3. في بيئة الاستضافة ضع المتغيرات التالية:

   ```text
   NODE_ENV=production
   ADMIN_PASSWORD=كلمة-مرور-طويلة-وفريدة
   COOKIE_SECRET=نص-عشوائي-طويل-وفريد
   DATA_PATH=/data/wats.sqlite
   WHATSAPP_VERIFY_TOKEN=رمز-سري-تختاره-أنت
   WHATSAPP_APP_SECRET=App-Secret-من-Meta
   TRUST_PROXY=true
   SECURE_COOKIES=true
   ENABLE_DEMO=false
   ```

4. من **WhatsApp → Configuration → Webhooks** ضع رابط Callback:

   ```text
   https://اسم-دومينك/webhook
   ```

5. ضع نفس قيمة `WHATSAPP_VERIFY_TOKEN` في خانة Verify token داخل Meta.
6. اشترك في حدث `messages`.
7. أرسل رسالة تجريبية إلى الرقم. يجب أن تظهر في اللوحة خلال ثوانٍ.

التطبيق يتحقق من توقيع `X-Hub-Signature-256` باستخدام `WHATSAPP_APP_SECRET`. لا تترك هذا المتغير فارغًا في الإنتاج.

## الاستضافة عبر Docker

الصورة جاهزة في `Dockerfile`. اربط مجلدًا دائمًا مع الحاوية في `/data` كي لا تفقد دليل العملاء عند إعادة النشر:

```bash
docker build -t wats-customers .
docker run --rm -p 3000:3000 --env-file .env -v wats-data:/data wats-customers
```

في ملف الإنتاج اجعل `DATA_PATH=/data/wats.sqlite`.

## الاختبارات

```bash
npm test
```

يغطي الاختبار تحقق Meta من Webhook، تخزين الرسالة، تسجيل الدخول، تعديل الاسم، وتصدير CSV.

## الخصوصية

- لا تضع `App Secret` أو كلمة مرور في المستودع؛ ملف `.env` مستثنى من Git.
- التصدير يحتوي أرقام العملاء، فاحفظه في مكان خاص.
- استخدم البيانات فقط لخدمة العملاء الذين تواصلوا معك، والتزم بسياسة الخصوصية المعلنة لنشاطك.
